# Climate Change: Regional Temperature Trends and Future Projections
DSC 106 Final Project Initial Prototype.

## Run
Upload `index.html`, `style.css`, `script.js`, and the entire `assets/` directory to the repository root. Enable GitHub Pages from `main` / `(root)`.

## Figures and provenance
All displayed values were transcribed from the team's **Final Project Proposal** (CESM2-WACCM model): historical warming ranking, decadal heatmap, projected continental averages, and projected warming rates. Historical lines, geographic map, and latitude scatter are **static crops of the team's own proposal figures**. The underlying raw annual and grid-cell data were not provided, so these figures are not falsely presented as interactive raw-data charts.

## Next iteration
