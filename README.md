# Climate Change: Regional Temperature Trends and Future Projections

DSC 106 Final Project — Initial Prototype

## How to view
Open `index.html` through GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)). No Mapbox token or local development server required.

## Files
- `index.html`: page structure and prototype writeups
- `style.css`: styling and responsive layout
- `script.js`: interactive D3 bar chart and continent selector

## Important: verify data before final submission
The chart currently uses five **provisional values from earlier project discussion** (Europe 1.69, North America 1.57, Asia 0.95, Africa 0.88, South America 0.62 °C). Check all values, comparison periods, methodology, and citations against your team's original proposal and underlying CMIP6 analysis before using them as research results. Do not treat these as independently validated figures.

## Planned final project
Historical climate trends (1950–2014), future CESM2-WACCM projections under SSP5-8.5 (2020–2099), and a connected visual narrative across five continents.
