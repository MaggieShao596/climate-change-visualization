Our climate explorer

So far, we've built the first version of our climate visualization website to compare temperature trends across five continents. We created an interactive line chart where users can hover over the lines to see values for different years. Users can also highlight a continent, adjust the year range, and switch between historical and future views. We've also worked on the website's design and are currently using demo data while preparing the real CMIP6 dataset.

The biggest challenge will be turning the large CMIP6 files into accurate temperature data for each continent. We need to calculate temperature anomalies using the same baseline so the regions can be compared fairly. Another challenge is keeping the chart easy to read when multiple lines overlap, especially when users explore different time periods. We also want to make sure our future projections are easy to understand without making them seem like guaranteed predictions.

Dataset & Methodology

Planned dataset: CMIP6 (Coupled Model Intercomparison Project Phase 6), CESM2-WACCM climate model. Our project focuses on near-surface air temperature (tas) across North America, South America, Europe, Africa, and Asia.

Time periods: Historical 1950–2014 and future 2020–2099 under the SSP5-8.5 scenario. We plan to calculate temperature anomalies relative to the 1951–1980 baseline. Note: the CMIP6 historical experiment ends in 2014 and the SSP experiments begin in 2015, so 2015–2019 is currently not shown in either view.

Data source: NOAA Public CMIP6 Dataset on Google Cloud . The real model data has not yet been integrated into this initial prototype.
